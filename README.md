## 🛠️ Featured Open-Source Projects

### 🚀 [n5](https://github.com)
A lightweight, modular deep-learning micro-framework built completely from scratch in Python and NumPy. 
* Supports brick-by-brick network assembly.
* Native implementations of Dense, Conv2D, MaxPool2D, Dropout, and custom layers.
* Features automated training loops with built-in backward pass execution.

### 🧠 [Tensor5](https://github.com) *(Upcoming)*
The next-generation evolution of the n5 framework. Tensor5 scales up from 2D vision networks into high-dimensional computing (3D and 5D Tensors) explicitly optimized for Large Language Models (LLMs), Self-Attention mechanisms, and Transformers.
